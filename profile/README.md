## About the project

AkewTutor is an online tutoring platform for Ethiopian learners in grades 1–12. It brings tutor discovery, class scheduling, payments, and learning activity into one place. Students can find academic support, parents can follow their children’s learning, and tutors can manage their teaching.

## One platform, four perspectives

| Role | Experience |
| :--- | :--- |
| **Student** | Discover tutors, manage classes, exchange messages, access materials, and review progress. |
| **Parent** | Link student accounts, follow schedules, manage payments, and access class resources. |
| **Tutor** | Maintain a teaching profile, rank subjects, publish availability, conduct classes, and review earnings. |
| **Admin** | Review tutors, manage matching, and oversee pricing, payments, and support requests. |

## Main features

| Area | What AkewTutor brings together |
| :--- | :--- |
| **Accounts and guardianship** | Registration, contact verification, sign-in, and parent–student relationships. |
| **Tutor discovery** | Subject-based search, recommendations, tutor profiles, and matching. |
| **Class delivery** | One-to-one and small-group formats, scheduled sessions, meeting links, and rescheduling. |
| **Payments** | Chapa checkout integration, payment history, billing status, and tutor earnings. |
| **Communication and resources** | Class conversations, notifications, recordings, and learning materials. |
| **Learning activity** | Tutor assessments, XP, badges, streaks, challenges, and leaderboards. |
| **Support** | Complaint tracking and support contact information. |

## How it works

1. **Create an account.** Register as a student, parent, or tutor and verify your contact details.
2. **Find a tutor.** Choose a subject, explore profiles, and select a tutor.
3. **Confirm the match.** Complete the required approval and payment steps.
4. **Attend lessons.** Follow the class schedule and open the lesson’s meeting link.
5. **Review learning activity.** Access materials, read tutor feedback, and follow progress.
